# Just Drive

**Just Drive** is a simple and engaging 2D web game where players must avoid oncoming obstacles while driving. The objective is straightforward: navigate your vehicle safely through a static environment filled with hurdles. The game tests your reflexes and timing, providing a fun and challenging experience.

Built using only HTML and CSS, **Just Drive** offers a smooth and minimalist design, making it accessible and easy to play right from your browser. It's perfect for quick, casual gaming sessions.

## Features
- **Easy Controls**: Intuitive gameplay with simple controls.
- **Static Environment**: The game environment remains consistent, with obstacles that appear as you drive.
- **Casual Gameplay**: Perfect for a quick break or to pass the time.
- **Smooth Animations**: Experience seamless transitions and animations using basic HTML and CSS.
- **Browser-based**: Play directly from any modern web browser without any downloads required.

## How to Play
1. **Start the Game**: Open the `index.html` file in any modern web browser (Google Chrome, Firefox, etc.).
2. **Control the Vehicle**: Use the arrow keys or [W/A/S/D] to move and avoid the obstacles.
3. **Avoid the Hurdles**: The goal is to survive as long as possible while dodging incoming obstacles.
4. **Compete for High Scores**: Keep track of your score and try to beat your personal best.
