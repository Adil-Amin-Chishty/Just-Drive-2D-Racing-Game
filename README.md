# 2D Racing Game

A simple, engaging 2D racing game where players control a car and avoid obstacles. The game features a scoring system, increasing difficulty, and responsive design.

## Features

- Car control using arrow keys or WASD
- Random obstacle generation
- Scoring system with best score tracking
- Increasing difficulty over time
- Responsive design for all devices
- Game over screen with restart option

## How to Play

1. Use the left and right arrow keys (or A and D) to move the car
2. Avoid the red obstacles
3. Score points by surviving longer and avoiding obstacles
4. Try to beat your best score!

## Technical Details

The game is built using:
- HTML5 Canvas for rendering
- Vanilla JavaScript for game logic
- CSS for styling and responsiveness
- Local Storage for saving best scores

## Installation

1. Clone this repository
2. Open `index.html` in a web browser
3. Start playing!

## Browser Support

The game works in all modern browsers that support HTML5 Canvas and ES6 JavaScript features.
